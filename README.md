## Project Description
This project extends the original **Lab 11 My Cafe** HTML and CSS assignment into a complete, responsive, 10-page coffee shop website built using pure **HTML5**, **CSS3**, and **vanilla JavaScript**. It preserves the original warm beige (`#F5F5DC`), brown (`#A52A2A`), and dark green (`#006400`) palette, Arial typography, cappuccino centerpiece image, `alert()` order interaction, and all original menu items and prices.

## Website Pages (Root Directory)
1. [index.html](index.html) — Homepage with hero, highlights, featured original drinks, illustrative offers, and gallery/testimonial previews.
2. [menu.html](menu.html) — Categorized menu tables (Coffee, Tea, Cold Drinks, Specialty Beverages, Bakery & Desserts) with live category filters and search.
3. [gallery.html](gallery.html) — Interactive photo gallery with modal lightbox preview.
4. [about.html](about.html) — Brand story, mission, vision, values, and illustrative team roles.
5. [coffee.html](coffee.html) — Coffee & tea educational guide covering bean varieties, roast profiles, and brewing parameters.
6. [experience.html](experience.html) — Cafe seating zones, study-friendly environment, and hospitality standards.
7. [events.html](events.html) — Illustrative coffee workshops, tastings, and community events calendar.
8. [reservation.html](reservation.html) — Table reservation enquiry form with JavaScript validation and demonstration confirmation.
9. [contact.html](contact.html) — Contact form and placeholder visit/opening-hours details.
10. [faq.html](faq.html) — Categorized FAQs with live keyword filter and accessible accordion controls.

## Shared Assets & Documentation
- `style.css` — Unified responsive stylesheet extending the Lab 11 color palette and table design.
- `script.js` — Vanilla JavaScript powering mobile navigation, menu search/filtering, gallery lightbox, FAQ accordion, form validation, and order alerts.
- `prompts.docx` — Documentation of key AI prompts and implementation results.

## Deployment
Hosted via **GitHub Pages** from the `main` branch (`/ (root)` folder).
